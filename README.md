# AI Detective Challenge

A classroom-friendly interactive quiz for introducing:
- Computer Vision
- Natural Language Processing (NLP)
- Data & Patterns

## Run locally
Open `index.html` in Chrome or Edge.

## Host with GitHub Pages
1. Create a GitHub repository, e.g. `ai-detective-game`.
2. Upload `index.html` to the root of the repository.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. GitHub will provide the published site URL.

The game does not require a server or database. Scores are kept only in the student's current browser session.
